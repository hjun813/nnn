# ApplyFlow 제품 기획서

## 1. 제품 개요

### 한 줄 소개

관심 있는 채용 공고의 마감과 준비 상태를 관리하고, 지금 해야 할 다음 행동을 알려주는 개인 지원 관리 서비스.

### 문제

취업 준비자는 여러 플랫폼에서 공고를 찾지만, 북마크·메신저·메모장 등에 흩어 놓은 뒤 다시 확인하지 않거나 마감일과 제출물을 놓친다. 공고별 준비 상태도 달라 어떤 지원을 먼저 진행해야 할지 판단하는 데 반복적인 비용이 발생한다.

### 해결 방향

사용자는 공고 URL을 붙여넣거나 직접 정보를 입력한다. ApplyFlow는 마감일, 목표일, 제출물과 준비 상태를 한곳에 모으고, 가장 급한 미완료 작업을 오늘의 행동으로 제안한다.

## 2. 목표와 비목표

### 목표

- 공고 등록 후 실제 지원으로 이어지는 비율을 높인다.
- 마감 또는 목표일을 놓치는 빈도를 줄인다.
- 여러 공고 중 지금 먼저 할 일을 10초 안에 파악하게 한다.
- 공고 한 건의 등록·확정 시간을 최소화한다.

### MVP 비목표

- 채용 공고 검색 및 추천 플랫폼
- 이력서·포트폴리오 제작 도구
- 자기소개서 생성 서비스
- 기업용 지원자 관리 시스템
- 면접 이후 전체 채용 프로세스 관리
- 파일 저장소, 외부 메신저 알림, 브라우저 확장 프로그램

## 3. 핵심 사용자

여러 기업에 동시에 지원하는 대학생, 취업 준비생, 인턴·신입 지원자와 이직 준비자다. 초기 검증에서는 한 달에 공고를 5개 이상 저장하고 2개 이상 지원하는 사용자를 우선한다.

## 4. 핵심 가치 제안

- 발견한 공고를 잊지 않는다.
- 목표일과 실제 마감일을 함께 관리한다.
- 필요한 제출물과 준비 상태를 한눈에 본다.
- 가장 급한 다음 행동을 바로 실행한다.
- AI가 등록을 돕되 잘못된 정보는 사용자가 수정한다.

## 5. 핵심 사용자 여정

```text
공고 발견
→ URL 분석 또는 직접 입력
→ 추출 결과 확인·수정
→ Saved
→ 제출물 준비
→ In Progress
→ 모든 준비 완료
→ 외부 사이트에서 지원
→ Applied
```

분석이 실패해도 직접 입력으로 즉시 전환할 수 있어야 한다.

## 6. MVP 범위

### 계정

- 이메일 회원가입·로그인·로그아웃
- 사용자 시간대 저장(초기 기본값 Asia/Seoul)
- 본인 데이터만 조회·변경

### 공고

- 직접 등록, 조회, 수정, 삭제 또는 보관
- URL, 회사명, 직무명, 플랫폼, 메모
- 실제 마감일, 개인 목표일, 상시 채용·미정 표현
- 중복 URL 경고

### 지원 관리

- Saved, In Progress, Applied 상태
- 내부적으로 Expired, Archived 상태 지원
- Resume, Portfolio, Essay 및 사용자 정의 작업
- Todo, In Progress, Done, Not Required 작업 상태
- 준비 진행률과 지원 상태 분리

### Dashboard

- 오늘 할 일
- 목표일 우선 D-Day
- 임박 순 정렬
- 이번 주 마감
- 준비 완료 후 지원하기 행동

### AI 보조 등록 — MVP 이후

- 초기 수동 등록 MVP에는 포함하지 않는다.
- URL 페이지 분석
- 회사, 직무, 마감, 제출물, 자소서 문항, 전형 정보 추출
- 분석 상태와 실패 원인 표시
- 결과 검토 후 사용자 확정
- 실패 시 직접 입력

### 인앱 알림

- D-7, D-3, D-1 알림 후보 생성
- 읽음 처리
- 중복 알림 방지

## 7. 후속 범위

- 이메일·모바일·메신저 알림
- 제출 파일 버전 관리
- 자기소개서 답변 검색과 재사용
- 코딩테스트·면접·결과 상태
- 캘린더
- 지원 통계
- 브라우저 확장 프로그램
- AI URL 공고 분석과 사용자 확인 흐름

## 8. 성공 지표

### 북극성 지표

주간 활성 사용자당 기한 내 완료된 지원 수.

### 핵심 지표

- Saved → Applied 전환율
- 목표일 또는 실제 마감일 이전 지원율
- 등록 시작 → 저장 확정 전환율
- 공고 저장 → 첫 작업 완료까지의 시간
- 사용자당 주간 활성 공고 수
- 4주 재방문율

### AI 품질 지표

- URL 분석 성공률
- 분석 완료 시간의 중앙값과 95백분위
- 필드별 사용자 수정률
- 잘못된 마감일 확정률
- 분석 실패 후 수동 저장 전환율

## 9. 주요 위험과 대응

| 위험 | 영향 | 대응 |
|---|---|---|
| 관리 자체가 일이 됨 | 이탈 | 기본 제출물 자동 생성, 빠른 상태 변경 |
| 페이지 수집 실패 | 등록 중단 | 직접 입력 fallback, 분석 비동기화 |
| AI 마감일 오류 | 기회 상실 | 근거 표시, 필수 사용자 확인, 추측 금지 |
| 상태·할 일 과다 | 대시보드 피로 | 공고별 최우선 행동 하나 노출 |
| 마감 공고 누적 | 목록 오염 | Expired 자동 판정과 보관 기능 |
| 민감한 구직 데이터 | 신뢰 저하 | 최소 수집, 접근 제어, 삭제 정책 |

## 10. 출시 기준

- 사용자가 3분 안에 첫 공고를 저장할 수 있다.
- 오늘 할 일에서 공고 상세 및 외부 지원 페이지로 이동할 수 있다.
- 날짜·시간대·상시 채용의 테스트가 통과한다.
- AI가 실패해도 공고 저장이 가능하다.
- 다른 사용자의 공고에 접근할 수 없다.
- 핵심 이벤트가 측정된다.
